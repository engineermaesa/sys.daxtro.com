## Cakupan regression

Pengujian tambahan meliputi hak akses dan tahap approve/reject; notes penolakan wajib; revisi terbuka menghalangi Submit to Finance; revisi lama read-only; edit langsung membentuk snapshot baru; konflik stale draft dan aksi bersamaan menghasilkan HTTP 409; nomor quotation tidak digunakan ulang; migrasi dan lazy snapshot data lama.

[QuotationDownstreamRegressionTest](../../tests/Feature/Leads/QuotationDownstreamRegressionTest.php) juga memeriksa proforma, signed document, pembayaran, incentive, dan expiry. Pemeriksaan ini menggunakan fixture dan mock untuk sebagian integrasi downstream; hasilnya tidak membuktikan seluruh layanan eksternal berjalan.

## Menjalankan ulang

Dari root repository:

```powershell
rtk proxy php tests/Integration/quotation-uat-local.php
```

[Runner lokal](../../tests/Integration/quotation-uat-local.php) memaksa konfigurasi testing, SQLite fixture, transport lokal, dan cache konfigurasi sementara. Runner tidak menerima argumen dan tidak menjalankan migrasi pada database aplikasi. Setiap run membuat direktori artefak baru di temporary directory, menyimpan JUnit, output, PDF dan manifest. Exit code bukan nol jika pengujian gagal, error, skipped, atau laporan tidak terbentuk.

Build aset dan pemeriksaan preview PDF pada laporan ini dilakukan terpisah dari runner. Artefak sementara dapat dibersihkan oleh sistem operasi; simpan salinannya jika diperlukan sebagai bukti release. Ikuti [deployment notes](deployment-notes.md) untuk persiapan migrasi berikutnya.
